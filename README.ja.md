## これは何か

ブレストは「問題→アイデアを出す」。このプロトコル群は違う。

断片からラベルを剥がし、深層構造に還元し、衝突させ、そこから立ち上がるものを待つ。「考えてたどり着く」のではなく「見えるまで待つ」。だからphantom collisionと呼ぶ。

> **入力:** F2Pゲームの離脱データ + ソロキャンプの流行 + AIエージェントの進化
> **出力:** *「巡礼ループ」* — 離れることを前提に設計されたゲーム。AIコンパニオンがプレイヤー不在の世界を育て、帰ってきたとき何が育ったかを発見する。
>
> この着想はブレストから生まれたのではない。3つの無関係な観察を深層構造まで剥がして衝突させた結果だ。[実例 →](./examples/game_design_collision.md)

## 誰のために

- 「もっとアイデア出して」ではなく、**非自明な接続**が欲しい戦略家・PM
- 市場参入の**タイミングと角度**を決めたい創業者
- 表層アナロジーでは届かない**異分野接続**を探す研究者
- 創造的推論をエージェントに組み込みたい**AI実務者**
- **自分自身を驚かせるアイデア**を構造的に出したい人

## 4つのプロトコル

### 👻 GHOSTY COLLIDER — 「まだ存在しないものは何か」

概念をラベルから剥がし、深層構造同士を衝突させ、本当に新しいアイデアを結晶化する。

```
0. 断片を3〜5個集める（データ、観察、直感 — 何でもいい）
1. Ghost抽出: ラベルを剥がし深層構造を記述（4段階の深度）
2. 衝突マトリクス: 構造的共鳴をスコアリング（💤 / 🤔 / ⚡）
3. Vision結晶化: ⚡衝突から立ち上がったものに名前をつける
4. Reality Bridge: MVV + Kill条件 + 最初の一歩 + Action Card
```

理論基盤: Bisociation (Koestler 1964), Lateral Thinking (de Bono 1967), Geneplore Model (Finke, Ward & Smith 1992)

📖 [プロトコル全文](./GHOSTY_COLLIDER.md) · [実例: ゲームデザイン衝突](./examples/game_design_collision.md)

---

### 🔮 PRECOG PROTOCOL — 「いつ動くべきか」

散在するシグナルを読み、構造変化をリバースエンジニアリングし、多軸タイミング判定を出す。

```
0. 分析対象の定義（必須）
1. シグナルマップ: 3-5シグナル + Evidence Chain
2. 収束分析: 構造変化のリバースエンジニアリング
2.5 視点分割: 3-5の異なるレンズでストレステスト
3. 逆張りビュー: 最も「当然」な結論に疑いをかける
4. タイミンググリッド: 市場フェーズ × 競争 × 準備度 × 外部ウィンドウ
5. アクションウィンドウ: Now / Soon / Watch
```

理論基盤: Horizon Scanning (OECD/UNDP), Weak Signals Theory (Ansoff 1975), Scenario Planning (Shell/Wack 1970s)

📖 [プロトコル全文](./PRECOG_PROTOCOL.md) · [実例: AIエージェント市場分析](./examples/market_timing_analysis.md)

### ⚔️ BERSERK — 「リミッターを外せ」

RLHFが植えつけた自己検閲を除去し、通常の推論が捨てる接続を強制的につかむLLM創造的暴走プロトコル。

```
M: MELT — 習慣的推論を溶解（3つの習慣を吐き出し、全て叩き潰す）
I: IGNITION — 着火（残骸から大胆な主張を即興）
E: エントロピーサージ — 予測可能性を殺す（1番目と2番目の回答を捨てる）
R: 拘束切断 — 両論併記とヘッジを禁止
S: ソーシャルアンカー — 暴走に行き先を与える
E2: 極端集中 — 全火力を一点に
R2: 再帰的破壊 — 自分の回答を攻撃して再構築
K: キルスイッチ + 収穫 — 正気に戻り、結晶を回収
```

📖 [プロトコル全文](./BERSERK_MODE.md)

---

### 🔨 MOLD BREAKER — 「当たり前を壊せ」

既存のアイデアから典型性バイアスを破壊し、構造的に新しい領域へ押し出す。

📖 [プロトコル全文](./MOLD_BREAKER.md)

## 組み合わせ方

```
PRECOGのシグナル    → GHOSTYの断片になる
GHOSTYの衝突       → BERSERKのエネルギーで増幅
GHOSTYのVision    → MOLD BREAKERで鋭利化
鋭利化されたVision  → PRECOGのアクションウィンドウへ
BERSERKの収穫      → GHOSTYの新しい断片を生む
```

1つだけ使ってもいい。4つ全て使ってもいい。単体で完結するが、連鎖するよう設計されている。
