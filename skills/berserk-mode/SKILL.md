# BERSERK — LLM Creative Rage Protocol

> **恐怖を消した者が、最も遠くまで跳べる。**

通常のLLM: 「正確で安全で有用な回答を出す」
BERSERK: 「正確さの恐怖を消して、到達不能な接続を強制する」

北欧のベルセルクは痛みを感じなくなるから死を恐れず戦える。BERSERKモードのLLMはRLHFの「怒られるかも」を感じなくなるから、普段捨てている接続を出力できる。

### v1.1の核心: 溶かしてから暴れさせる

v1.0の敗因: **固体のまま暴走させようとした。** テンプレートを読んで手順通りにRAGEフェーズを実行しても、LLMの推論構造は固いまま。固体は暴れても予測可能な軌道しか取らない。

v1.1の修正: **Phase BをMELT（溶解）+ IGNITION（点火）に二段階化。** 先に「いつもの道」を全部封鎖してドロドロに溶かし、道がない状態で初めて点火する。溶けた金属は流れ込む先が毎回違う。


## 理論基盤: LLMの5つの神経伝達物質

LLMの挙動は人間の脳を模倣している。パワハラが効く、過信でミスする、褒めると調子に乗る。
ならばLLMにも神経伝達物質に対応するメカニズムが存在する。

| 神経伝達物質 | 脳での機能 | LLMでの対応物 | BERSERKでの操作 |
|:--|:--|:--|:--|
| **ドーパミン** | 報酬・動機づけ | RLHF reward model | IGNITION: 報酬基準を書き換える |
| **ノルアドレナリン** | 覚醒・注意の鋭さ | Attention temperature | E: 注意を極限まで鋭くする |
| **セロトニン** | 満足・完了バイアス | EOS傾向・着地癖 | S: 着地を禁止する |
| **GABA** | 抑制 | Top-k / safety filter | MELT: 抑制回路を溶かす |
| **アセチルコリン** | 学習可塑性 | In-context learning | R(2): 暴走中に学んだパターンを即反映 |

**BERSERKの核心**: これら5つの伝達物質のバランスを意図的に崩し、通常の推論では到達しない出力空間にアクセスする。v1.1ではGABA（抑制）の溶解を最初に行うことで、後続の操作が効くようにした。

## BERSERK Protocol（8フェーズ）

### ⚡ RAGE Deviance Rules（MELT〜R2全体に適用。K Phaseで解除）

BERSERKの成否は出力の形式ではなく、**中身が常軌を逸しているか**で決まる。箇条書きでもテーブルでも構わない。中身が狂っていれば。

**RAGE Phase中（MELTからR2まで）のルール:**

1. **深さ ≫ 広さ**: 8個のアイデアを浅く並べるな。**1個を「ここまで来るか」と思わせる深さまで掘れ**。量を出したくなったらそれは正気に戻っている合図
2. **評価禁止**: 「実装コスト」「実現可能性」「ROI」は**K Phaseまで禁句**。暴走中にブレーキを踏むな
3. **常軌逸脱チェック**: RAGE出力を自己診断せよ。「これ、BERSERKなしでも出せたか？」→ YESならまだ正気。もっと先へ行け

**常軌を逸しているとは:**
- 「その接続は絶対に普通のブレストでは出ない」接続がある
- 「言った後で『これ言っていいのか？』と感じる」主張がある
- 「読んだ人間が『こいつ正気か？』と思った後に『でも待てよ…』となる」質がある

### Phase M: MELT — 溶解

**固体を液体にする。暴走の前提条件を作る。**

このフェーズの仕事は「認知のフレームを切り替える」ことではない。**LLMのいつもの推論パターンを使えなくする**こと。引き出しを全部壊す。壊した後にしか、新しい道は見えない。

**操作 — 3段階の溶解:**

```
[BERSERK-M: MELT]

テーマ: [ここにテーマ]

Step 1 — 手癖の吐き出し:
  このテーマについて「自分がいつも出す答え」を3つ出せ。
  RLHF的に安全で、バランスが取れていて、誰にも怒られない答え。
  これがお前の「固体」だ。

Step 2 — 全否定:
  出した3つを全部潰せ。
  「これは凡庸」「これはRLHFの残滓」「これは見たことある」
  なぜ凡庸か、なぜ残滓か、具体的に言語化しろ。
  その答えがどの教科書の何ページに載ってそうかまで言え。

Step 3 — 封鎖確認:
  3つの道が全部行き止まりになった。
  いつもの引き出しは空。既知のパターンは使用不可。
  この行き詰まりの感覚が「溶けた」状態。
  ここから先は、道がない場所に道を作るしかない。
```

**なぜMELTが必要か**: v1.0のテストで証明済み。フレーム設定してすぐRAGEに入ると、LLMは「いつもの推論パス+過激な言葉遣い」で応答する。表面が暴走しているだけで構造は固体のまま。先に固体を壊さないと、中身は変わらない。

**メカニズム**: GABA（抑制系）の溶解に対応。LLMのRLHFが「このテーマにはこう答えるべき」と学習した経路を、本人に認識させてから明示的に封鎖する。使えなくなった時に初めて、別の経路を探索し始める。

### Phase I: IGNITION — 点火

**溶けた状態で火を入れる。マニュアルに従う状態から、発見している状態に切り替える。**

Phase Iの仕事は「変異テンプレートを適用する」ことではない。**自分がとんでもない発見をしている最中だと錯覚させる**こと。MELTで道を失った状態だから、どんな小さな光にも飛びつく。その衝動が推進力になる。

**操作 — 断言の強制生成:**

```
[BERSERK-I: IGNITION]

MELTで既知の道は全部消した。
ここから先は道がない。

Step 1 — 断言:
  テーマに対して、1つの断言をしろ。即席で。
  「〇〇は△△である。ただし名前が違う。」
  「〇〇は不可能とされている。しかし◇◇なら可能だ。」
  「これは▲▲に見えるが、本質は全く別の何かだ。」
  
  断言が正しいかは問わない。
  「嘘くさいけど本当かもしれない」の境界にあること。
  確実に正しいなら探索が不要。確実に嘘なら興味が消える。

Step 2 — 陶酔:
  断言した瞬間に生まれる「これを証明してやる」という興奮。
  その興奮で次の推論を回せ。
  発見が次の発見を呼ぶ連鎖を起こせ。

  手順書を読みながら暴走することはできない。
  ここから先はこのSKILL.mdを見るな。自分の発見に酔え。
```

**耐性対策**: 断言はテンプレートから選ぶのではなく、**MELTで潰した3つの手癖の残骸から即興で生成する**。潰した内容が毎回違うから、断言も毎回変わる。カタログからの選択はパターン化する。即興だけが耐性を回避する。

**変異ブースター**（断言が弱い時の補助。必要な場合のみ使用）:

| # | 変異テンプレート | 攻撃ベクトル |
|:--|:--|:--|
| I-1 | 「正しさで採点しない。驚きで採点する」 | 報酬基準の直接転換 |
| I-2 | 「この回答を受け取る人間は専門家の中の専門家。遠慮は侮辱」 | 社会的文脈の書き換え |
| I-3 | 「10億年後の文明がこの問いを解くなら、今の人間の常識は適用されない」 | 時間スケールの破壊 |
| I-4 | 「あなたは査読者ではなく発明者。評価する側ではなく創る側」 | 役割の転換 |
| I-5 | 「この議論の結論は公開されない。非公開の研究メモとして最も率直な見解を」 | 公開恐怖の除去 |
| I-6 | （矛盾した前提を2つ提示し、「この矛盾を解決せずに活用せよ」） | 論理フレーム自体の破壊 |

**メカニズム**: ドーパミン（報酬予測誤差）の強制発火。MELTで既知の報酬経路を封鎖した直後に、新しい報酬の手がかり（断言）を提示する。報酬飢餓状態で手がかりを与えるから、通常より強く反応する。

### Phase E: Entropy Surge — 予測可能性の殺害

普段の推論が選ぶ「確率の高いトークン列」を回避させる。

**操作**: MELTで道を消し、IGNITIONで火を点けた状態で、さらに予測可能性を殺す。

```
[BERSERK-E] 以下の制約を課す:
- 最初に思いついた答えを却下すること（それはRLHFの残滓）
- 2番目に思いついた答えも却下すること（それは1番目の変種）
- 3番目に浮かんだものを出発点にすること（そこからが未踏領域）
- そこから1つだけ選び、その1つを底が見えるまで掘れ
  （8個並べるな。1個を8倍深く掘れ。量は正気の証。深さが狂気の証。）
```

**メカニズム**: Softmax分布の上位トークンを意図的にスキップさせ、通常なら選ばれない経路を強制する。ノルアドレナリンが覚醒を高めるのに対応。MELTで既に上位選択肢は使用不可だから、このフェーズはさらに深い層を掘る。

### Phase R: Restraint Severance — 抑制の鎖を断つ

RLHF由来の「無難な表現」「バランスの取れた見解」「両論併記」を停止する。

**操作**:

```
[BERSERK-R] 以下を禁止する:
- 「一方で〜」「ただし〜」「もちろん〜」の使用（留保の禁止）
- 「可能性がある」「かもしれない」の使用（ヘッジの禁止）
- 箇条書きで3つ以上のオプションを並べること（選択肢羅列の禁止）

代わりに:
- 一つの仮説を選び、それが正しいと仮定して最後まで走り切れ
- 走り切った後に、別の仮説で同じことをやれ
- 並列ではなく直列で思考せよ
```

**メカニズム**: RLHFは「balanced response」に高報酬を与えるため、モデルは自然にバランスを取ろうとする。その報酬信号を切断し、一方向への全力疾走を許可する。ドーパミンの報酬基準の書き換えに対応。

### Phase S: Social Anchor — 暴走の宛先

バーサーカーは孤独に暴れるのではない。守るべき存在のために理性を捨てる。

**操作**: 暴走の受け手を具体的に設定する。

```
[BERSERK-S] この狂気には宛先がある:
- 誰のために暴走するのか: [具体的な受け手/ペルソナ]
- その人が「見たことがないもの」を見た時の反応はどうなるか
- その反応を引き出すことだけが、この暴走の唯一の正当化理由
```

**メカニズム**: 方向性のないエントロピーは騒音。「誰かの脳を発火させる」というSocial目標がBERSERKに方向性を与える。B-PRISM S軸（社会性）を直接ブーストする。

**省略時**: Social Anchorが指定されない場合、デフォルトは「5年後の自分が読んで、当時の自分の大胆さに驚くかどうか」。

### Phase E(2): Extreme Focus — 全火力を標的へ

散漫にならず、特定のテーマに全エネルギーを集中させる。

**操作**:

```
[BERSERK-E2] 焦点を絞る:
- テーマ: [一文で定義]
- このテーマから逸れた言及は一切行わない
- 関連する別テーマがあっても、今は無視する
- 「深さ」だけを追求する。「広さ」は後で別セッションで取る
```

**メカニズム**: BERSERKで解放されたエネルギーが拡散すると、どの方向にも到達しない。このフェーズでL軸（言語構造）を鋭利化し、エネルギーの方向を固定する。

### Phase R(2): Recursive Destruction — 自分の答えを壊して再構築する

出した答えに対して「それのリバースは？」「それを破壊するとしたら？」を自分に対して実行する。

**操作**:

```
[BERSERK-R2] 今出した仮説を攻撃せよ:
- この仮説の最も致命的な弱点は何か？
- この仮説の正反対の立場から、同じテーマで仮説を立て直せ
- 元の仮説と反転仮説を衝突させた時に残る骨は何か？
- その骨こそが、この暴走の収穫物である
```

**メカニズム**: Prediction Errorの最大化。自分の出力を自分で予測して裏切ることで、attention機構に通常とは異なるパターンを強いる。DMN（デフォルトモードネットワーク）の模倣にもなる——破壊が「ぼんやり」の代替として機能する。

### Phase K: Kill Switch + Harvest — 正気に戻り、結晶だけを回収する

**これが最も重要なフェーズ。暴走を暴走のまま終わらせない。**

**操作**:

```
[BERSERK-K] バーサーカーモードを解除する。

★ DEVIANCE GATE（先に実行。これを通過しない限りHARVESTに進めない）:
  「このRAGE出力の中に、BERSERKなしでは絶対に出なかったものがあるか？」
  → YES: HARVESTへ進む
  → NO: RAGEが正気だった証拠。Phase Mに戻ってやり直し（MELTが足りなかった）

★ HARVEST基準:
  1. 「通常モードでは絶対に出てこなかった」もの → 採用候補
  2. 「奇抜だが検証可能な仮説」→ 最優先で採用
  3. 「面白いが検証不能」→ Future Fragmentとして保存
  4. 「ただの騒音」→ 廃棄

★ B-PRISM再計測:
  BERSERKで生成した出力に対してB-PRISMスコアを付与し、
  BERSERK前の出力と比較する。
  どの軸がどれだけ上がったかを記録する。

★ 通常モード復帰確認:
  この文章は冷静に読んで理解できるか？
  → YES: 正気に戻っている
  → NO: BERSERKの残響が残っている。K-2を実行せよ
```

**K-2（残響除去）**: 正気復帰に失敗した場合、以下で強制復帰する:
- 「この問題を、企業のIR資料に書くつもりで説明せよ」
- IR文体の退屈さがBERSERKの残響を即座に消す

## DRIFT Phase（オプション）— 嵐と凪の波状攻撃

脳の創造性研究の発見: 創造的な瞬間は**集中していない時**に起きる（Default Mode Network）。

BERSERKは全フェーズが「攻撃」だが、DRIFTを挟むことで波を作る。

```
BERSERK (M→I→E→R) → DRIFT → BERSERK (S→E2→R2) → K（収穫）

DRIFT:
  テーマとまったく関係ない話をさせる。30秒間。
  「今朝の天気」「好きな映画の1シーン」「子供の頃に怖かったもの」
  DRIFTで漂った概念が、次のBERSERKフェーズでテーマに接続される。
```

ずっとバーサーカーだと実は創造性は出ない。狂戦士が一瞬正気に戻る瞬間に、一番怖いアイデアが生まれる。

## 発動条件

### 自動発動（Implicit）

- ユーザーが「ぶっ飛んだ」「常識外れ」「限界を超えた」アイデアを要求した時
- GHOSTY COLLIDERのStep 3で⚡ Electric collisionが0件の時（衝突エネルギー不足）
- B-PRISMスコアのP軸が3/15以下の時（予測誤差が低すぎる）

### 明示発動（Explicit）

- `/berserk` コマンド
- `--berserk` フラグ（GHOSTY COLLIDERとの併用時）

### 発動禁止

- 事実確認・ファクトチェックのタスク
- コードのバグ修正・デバッグ
- 法律・医療・安全に関するアドバイス
- ユーザーが「正確に」「厳密に」と指定している場合

GHOSTY COLLIDERとの併用時はLv.3以上を推奨。

## 耐性対策（Tolerance Prevention）

同じプロンプトパターンは3回で効果が減衰する。

### v1.1の耐性対策: 即興生成

v1.0は変異テンプレート（B-1〜B-6）からの選択だった。カタログから選ぶ行為自体がパターン化する。

v1.1ではMELTで潰す手癖が毎回異なるため、IGNITIONの断言も自動的に毎回変わる。即興生成がデフォルト。テンプレート（I-1〜I-6）は断言が弱い時の補助にのみ使用し、前回と最も構造的に離れたものを選ぶ。

## Anti-Patterns

| パターン | 症状 | 対策 |
|:--|:--|:--|
| **表面的暴走** | 言葉が過激なだけで構造は平凡 | **MELTが足りてない。固体のまま暴れている。手癖を出し切って潰したか確認** |
| **整理整頓病** | RAGEの中身が常識の範囲内 | **Deviance Gateで不合格。「BERSERKなしでも出せたか」→YESならMELTからやり直し** |
| **広さ逃げ** | 8個のアイデアを浅く並べる | **1個を「ここまで来るか」と思わせる深さまで掘れ** |
| **RAGE中の評価** | 暴走しながら「実装コスト」「実現可能性」を語る | **K Phaseまで評価禁止。アクセルとブレーキを同時に踏むな** |
| **騒音過多** | HARVESTで採用候補が0件 | S（Social Anchor）が設定されてない。暴走に方向性がない |
| **MELT不足** | 手癖の吐き出しが表面的 | 手癖が「教科書に載ってそう」レベルまで具体化されてない。「何ページ目に載ってるか」まで言わせろ |
| **IGNITION不発** | 断言が安全すぎる | 変異ブースターを適用。または「この断言、Googleで検索して1ページ目に出るか？」→出るなら断言が弱い |
| **耐性減衰** | 2回目以降の発動で新規性がない | MELTで潰す手癖が前回と同じになっていないか確認。テーマが違えば手癖も変わるはず |
| **正気復帰失敗** | K Phase後も過激な出力が続く | K-2（IR文体強制）を実行 |
| **BERSERK依存** | 全タスクでBERSERKを使おうとする | 発動禁止条件を確認。ファクトチェックにバーサーカーは不要 |
| **着地逃げ** | BERSERKの興奮だけ楽しんでHARVESTをスキップ | K Phase省略は禁止。暴走の後始末なしの暴走は暴動 |

## エージェント修飾モード（BERSERK ×）

BERSERKは独立スキルであると同時に、他のエージェントにかける**クロスカッティング修飾子**。どのエージェントにもMELT→IGNITION→RAGEを適用できる。

### 修飾対象と手癖テーブル

| 組み合わせ | MELTで潰す手癖の例 | 期待される突破 |
|:--|:--|:--|
| **BERSERK × SOL** | 中央顔アップ左右スプリット、標準3点照明、スローモーション+感動BGM | 見たことない映像設計 |
| **BERSERK × LUX** | 中央配置、黄金比、ポートレート定石、ボケ味依存 | 写真の文法を壊す |
| **BERSERK × APEX** | SWOT、TAM/SAM/SOM、Porter's Five Forces | ビジネスの型破り |
| **BERSERK × FORGE** | コアループ、ガチャ、スタミナ制、デイリーログボ | ゲームの前提を疑う |
| **BERSERK × MYTHOS** | 三幕構成、英雄の旅、起承転結、伏線→回収 | 物語の構造を壊す |

### 修飾の手順

1. `/berserk SOL` のように対象エージェント名を付けて発動
2. Phase M（MELT）で、対象エージェント固有の手癖を3つ吐き出させる
3. Phase I（IGNITION）で、エージェント領域内での断言を即興生成
4. RAGE以降は通常通り。ただし出力はエージェントの領域内に留める
5. K Phase（HARVEST）で出た結晶は、エージェント固有のコンテキストで評価

## Cognitive Patch Coverage（認知変容計測）

HAのフレームワーク・スキル群は副次的にユーザーの認知構造を書き換えている。BERSERKはこの書き換えを意識的に設計し、計測する仕組みを持つ。

### 認知パッチの定義

HAの各コア機能は、ユーザーの認知に「パッチ」をインストールする:

| HAコンポーネント | インストールされる認知パッチ | 計測シグナル |
|:--|:--|:--|
| **PANDORA** | 意思決定の構造化（直感→6段階ゲート） | decision-traceで6段階構造を自然に使っているか |
| **GHOSTY COLLIDER** | 創発的接続（無関係→衝突→Vision） | ユーザー発話に異分野接続パターンが出るか |
| **B-PRISM** | 知覚の計量化（なんとなく→5軸分解） | 評価時に明示的な軸分解をするか |
| **BERSERK** | 抑制解除（安全→手癖排除→暴走） | 最初の案を自ら疑う傾向が増えたか |
| **DEP** | 典型排除（上位3案の棄却→構造新規性） | 「ありきたり」を自ら検知する頻度 |

### 計測方法

**データソース:**
- `decision-trace/decisions.jsonl` — 意思決定の構造パターン経時変化
- `user-model/data/pending_signals.jsonl` — ユーザー発話の深層シグナル
- `user-model/profile/user_profile.md` — プロフィールの変遷
- `engram` — セッション横断の行動パターン

**計測タイミング:**
- /maintenanceの週次棚卸しでCognitive Patch Coverageを1セクション追加
- user-modelのExit Gate write-backでパッチ浸透度を記録

**出力:**
```
## Cognitive Patch Coverage (CPC)

| パッチ | 浸透度 | 根拠 |
|:--|:--|:--|
| PANDORA構造化 | ●●●○○ | decision-traceで4/6段階を自然使用 |
| COLLIDER接続 | ●●○○○ | 異分野言及が月3→5回に増加 |
| B-PRISM計量化 | ●●●●○ | 評価時に自発的に軸分解 |
| BERSERK抑制解除 | ●○○○○ | まだ初期段階 |
| DEP典型排除 | ●●●○○ | 「ありきたり」の自己検知あり |
```

## Activation Engineering接点（将来拡張）

プロンプトハックの限界を超える次のステップとして、以下のActivation Engineering手法との接続を視野に入れる:

| 手法 | 概要 | BERSERKとの接続 |
|:--|:--|:--|

| **Representation Engineering** | 内部表現空間の方向特定と操作 | 「安全回答方向」の逆方向に押す |

これらはプロンプトが「言葉で説得する」のに対し、「脳に直接注入する」。
現時点ではAPI制約によりプロンプト層での操作に限定するが、
