# GHOSTY COLLIDER — Creative Phantom Collision Engine

> **Collide the ghosts of concepts to birth things that don't yet exist.**

Standard brainstorming: "Problem → Generate ideas."
GHOSTY COLLIDER: "Fragments → Strip labels → Collide → Wait for emergence."

**You don't think your way to a vision. You wait for it to appear.** That's why it's called a phantom collision.

---

## Theoretical Foundation

GHOSTY COLLIDER is grounded in three established creativity theories, re-engineered as an executable protocol for AI agents:

| Theory | Author | Core Insight | How GHOSTY COLLIDER Applies It |
|--------|--------|-------------|-------------------------------|
| **Bisociation** | Arthur Koestler (1964) | Creativity occurs when an idea is perceived simultaneously in two self-consistent but habitually incompatible frames of reference | **Ghost Extraction** strips the original frame; **Collision Matrix** forces intersection of incompatible frames |
| **Lateral Thinking** | Edward de Bono (1967) | Breaking dominant patterns enables creative leaps; provocation disrupts habitual thought | **Ghost化 (de-labeling)** is a systematic provocation — removing the familiar name forces lateral perception |
| **Geneplore Model** | Finke, Ward & Smith (1992) | Creativity = Generate (pre-inventive structures) → Explore (interpret & refine) | Steps 1-3 = Generate phase; Steps 4-5 = Explore phase |

**What makes GHOSTY COLLIDER different from these theories:**
These theories describe *how creativity works*. GHOSTY COLLIDER prescribes *how to make it happen on demand*, as a repeatable 5-step protocol that an AI agent can execute. The key innovation is **Ghost Extraction** — systematically reducing concepts to their deep structure (verbs, forces, transformations) before collision, which dramatically increases the probability of non-obvious connections.

## The Ghost Protocol (5-Step Procedure)

### Step 1: Fragment Harvest


Collect fragments from the user. **Anything qualifies.**

Harvest targets:
- 📊 **Data & metrics** — revenue trends, KPIs, market data
- 👁️ **Observations** — user behavior, competitor moves, tech shifts
- 🫠 **Gut feelings** — "Something feels off about this," "This bugs me"
- 🎨 **Aesthetic impressions** — "I love this design," "This atmosphere"
- 🚫 **Absences** — "Why doesn't this exist?"
- 💭 **Personal experiences** — travel, conversations, failures, successes
- ⛓️ **Constraints** — budget, tech limitations, regulations, headcount

Minimum 3 fragments, ideal 5. **The more unrelated they are, the better.**

If the user hasn't specified fragments:
```
GHOSTY COLLIDER activated.
Hand me the fragments to collide.
Data, feelings, gut reactions, experiences — anything works. Minimum 3.
```

---

### Step 2: Ghost Extraction (De-labeling)

**Strip each fragment of its label and extract the deep structure (Ghost).**

This is the most critical step. Labels keep you inside existing frames. Remove them.

#### Ghost Depth Scaling (experimental)

Inspired by A-RAG's Test-Time Scaling finding: *"Stronger reasoning models benefit more from increased compute."* The same principle applies to Ghost Extraction — giving more cognitive depth produces qualitatively different Ghosts.

| Depth | Effort | Extraction Target | Token Cost |
|-------|--------|-------------------|:---:|
| `shallow` | Quick | Function: "What does this do?" | Low |
| `medium` | Default | Structure + Emotion: "What is this, fundamentally?" | Medium |
| `deep` | Deliberate | Hidden tension: "What contradiction does this contain?" | High |
| `abyss` | Maximum | Ontological: "What does this reveal about how humans relate to reality?" | Very High |

**Default is `medium`.** Use `deep`/`abyss` when fragments are familiar or when the collision needs to produce non-obvious results. `shallow` is for speed runs or when you have 7+ fragments.

**Depth selection heuristic:**
- User says "quick ideas" / 7+ fragments → `shallow`
- No depth specified → `medium`
- User says "go deep" / "dig harder" / "幻視して" → `deep`
- User says "abyss" / explicitly requests maximum depth → `abyss`

Procedure:
1. Write the fragment's name (label)
2. Select depth (default: `medium`)
3. Ask the depth-appropriate question
4. Describe using only structure — no proper nouns, no industry jargon

Format:
```
Fragment: "Gacha mechanics"
  ↓ Ghost Extraction (medium)
Ghost: "A device that converts uncertainty into pleasure"

  ↓ Ghost Extraction (deep)
Ghost: "A machine that monetizes the gap between who you are and who you
        want to be — the pull is not the prize, but the moment of possibility"

  ↓ Ghost Extraction (abyss)
Ghost: "A ritual of voluntary self-deception where the participant pays to
        temporarily believe that luck is a personal attribute — the transaction
        is not money-for-item, but money-for-the-feeling-of-being-chosen"
```

### Ghost Extraction Quality Checklist:
- ✅ **Uses verbs**: Structure reads as "X transforms Y into Z"
- ✅ **Includes emotion**: Not just function but what the experiencer *feels*
- ✅ **No jargon**: A person from a completely different industry would understand it
- ✅ **Reversible test**: Try writing "NOT [Ghost]" — if it reveals something new, the Ghost is deep enough
- ✅ **Depth-appropriate**: `deep`/`abyss` Ghosts should contain a **tension or paradox**
- ❌ **Too shallow**: If the Ghost is just a synonym of the label, go deeper
- ❌ **Depth mismatch**: A `deep` Ghost that reads like a `shallow` one — re-extract

---

### Step 3: Collision Matrix

**Intentionally collide extracted Ghosts against each other.**

You don't need all combinations. Search for **structural resonance**:
- Deep structures that are **similar** (despite surface-level irrelevance)
- Deep structures that are **opposite** (creates tension/energy)
- One Ghost **fills the gap** that another has

Collision Scoring:
| Score | Meaning | Action |
|-------|---------|--------|
| 💤 Boring | Surface AND structure are similar | Discard |
| 🤔 Interesting | Structural overlap exists | Hold |
| ⚡ Electric | Surface is unrelated BUT structure resonates/clashes | **Advance** |

**Only ⚡ Electric collisions proceed to Step 4.**

Output:
```
Collision: Ghost A × Ghost B → ⚡ Electric
Resonance: [Why these two connect structurally, in one sentence]
```

---

### Step 4: Vision Crystallization

From ⚡ Electric collisions, **something emerges**. This thing existed in neither Fragment A nor Fragment B. It was born from the collision.

For each emergence:
1. **Name** — Give the unnamed thing a name
2. **One Line** — "[Name] is a [thing] that [does what] for [whom]"
3. **Feel** — What would someone experiencing this feel? (1-2 emotion words)
4. **Image** — Describe one concrete scene cinematically
5. **Why Now?** — Why is this possible now? Why couldn't it have been done before?

Format:
```
👻 VISION: [Name]

"[One Line]"

Feel: [Emotion]
Image: [Concrete cinematic scene description]
Why Now: [Reason this is timely]
```

Multiple collisions may yield multiple Visions. Present all and let the user choose.

---

### Step 5: Reality Bridge

Visions are beautiful, but beauty alone isn't enough. **If you said "create," you must build a bridge to reality.**

- **Minimum Viable Vision (MVV)**: What's the smallest thing that reproduces this experience?
- **Existing Capability**: What current tech/resources/skills get us closest?
- **Kill Conditions**: What would kill this? (Tech impossibility, no market, legal barriers)
- **First Step**: What can be done starting tomorrow?

### Action Card Generation

Convert Reality Bridge items into an **Action Card**:

```
📋 ACTION CARD: [Vision Name]
├── Priority: Now / Soon / Watch
├── MVV: [One-line minimum viable definition]
├── First Step: [What can be done tomorrow]
├── Owner: [Who does this]
├── Trigger: [Start condition] (for Soon/Watch)
├── Kill Condition: [Abort condition]
└── Connect: → Integrates with precog-protocol Action Window
```

**Action Cards use the same Now/Soon/Watch classification as `precog-protocol`**, enabling direct integration between creative visions and strategic action planning.

## End-to-End Example

**User input:** "Collide these: F2P game churn data showing slow decline but high return rate, the solo camping boom in Japan, and the rapid evolution of AI agents."

### Step 1: Fragment Harvest
| # | Fragment |
|---|----------|
| 1 | F2P game: DAU declining slowly, but return rate is unusually high |
| 2 | Solo camping is booming in Japan — people pay to be alone in nature |
| 3 | AI agents are evolving from tools to autonomous collaborators |

### Step 2: Ghost Extraction
| # | Fragment | Ghost |
|---|----------|-------|
| 1 | F2P churn + high return | "Not desertion but pilgrimage — periodic departure from a place that still holds meaning" |
| 2 | Solo camping boom | "Paying for structured solitude that restores agency and presence" |
| 3 | AI agent evolution | "A non-human entity graduating from servant to companion" |

### Step 3: Collision Matrix
| A × B | Score | Resonance |
|-------|-------|-----------|
| 1 × 2 | ⚡ | Both involve **voluntary departure** that paradoxically strengthens connection. Campers leave civilization to appreciate it; players leave a game to return refreshed |
| 1 × 3 | 🤔 | AI as companion could change what "returning to a game" means |
| 2 × 3 | ⚡ | Solo camping = restoring agency through solitude. AI companion = restoring agency through delegation. **Both are mechanisms for reclaiming control** |

### Step 4: Vision Crystallization

👻 **VISION: The Pilgrimage Loop**

"A game that is *designed* to be left — and designs the leaving as part of the experience. An AI companion tends to your world while you're away, and when you return, it shows you what grew in your absence."

- **Feel:** Wonder, nostalgia, gentle surprise
- **Image:** A player opens the app after 2 weeks away. Their AI companion says, "While you were gone, the garden bloomed. A traveler visited — they left you a letter." The world didn't freeze. It lived.
- **Why Now:** AI agents can now autonomously tend to game worlds. Before 2025, NPCs could only run scripted events. Now they can make contextual decisions, making "off-screen life" genuinely surprising.

### Step 5: Reality Bridge

📋 **ACTION CARD: The Pilgrimage Loop**
- **Priority:** Soon
- **MVV:** A prototype where an AI agent generates one meaningful change per day in a player's world while they're offline. Test with 100 players for 30 days.
- **First Step:** Define 10 possible "world events" an AI could generate during player absence. Rank by emotional impact.
- **Owner:** Game design lead
- **Trigger:** AI agent API becomes stable enough for daily autonomous actions
- **Kill Condition:** Players don't notice or care about the changes when they return (measured by session length on return day)
- **Connect:** → precog-protocol Action Window (track AI agent API maturity as a signal)

## Quality Metrics for Visions

Rate each Vision on these 4 dimensions:

| Dimension | Question | Score |
|-----------|----------|-------|
| **Novelty** | Does this exist already? Could you Google it? | ⭐1-5 (5 = nothing like this exists) |
| **Feasibility** | Can the MVV be built with current technology? | ⭐1-5 (5 = buildable today) |
| **Resonance** | Does this make someone say "I want that"? | ⭐1-5 (5 = immediate emotional pull) |
| **Timing** | Is there a reason this should happen *now*? | ⭐1-5 (5 = clear window of opportunity) |

**Threshold:** A Vision must score ≥ 3 on all four dimensions to advance to Reality Bridge. If any dimension scores 1, the Vision is discarded or recycled as a new Fragment.

**Sweet spot:** Novelty ≥ 4 AND Feasibility ≥ 3 — this is the zone where innovation meets execution.

## Anti-Patterns (How This Goes Wrong)

| Anti-Pattern | Symptom | Fix |
|-------------|---------|-----|
| **Shallow Ghosting** | Ghost is just a synonym of the label ("Gacha" → "Random reward system") | Go deeper. Ask "Why does this *feel* the way it does?" not just "What is this?" |
| **Electric Inflation** | Every collision is scored ⚡ | Be ruthless. If you can explain the connection in 2 seconds, it's 🤔 at best. ⚡ should surprise you. |
| **Vision Without Grounding** | Beautiful concept but no Reality Bridge | Never skip Step 5. A vision you can't MVV is a daydream. |
| **Homogeneous Fragments** | All fragments come from the same domain | Demand diversity. "Give me something from outside your industry." |
| **Forced Collision** | Connecting fragments that don't actually resonate, just to produce output | It's OK to report "No ⚡ Electric collisions found. Try different fragments." |
| **Why Now = Never** | Vision sounds cool but could have been done anytime | If the answer to "Why Now?" is "no reason," it's a Watch at best. |

---

## Guardrails

- **De-labeling is reframing, not fabrication**: Ghost Extraction reveals alternate perspectives. It does not invent facts.
- **No Electric inflation**: If everything is Electric, nothing is. Only genuine structural resonance qualifies.
- **Never reject a fragment**: Every fragment is material. "That's not useful" is never the right response.
- **Never skip Reality Bridge**: A vision without a bridge to reality is just a daydream.
- **"Why Now?" is mandatory**: A Vision that can't answer "Why Now?" is demoted to Watch.

## 🏟️ PHANTOM ARENA — Multi-Context Collision (Conditionally Mandatory)

> Inspired by MiroFish's dual-platform parallel simulation (Twitter + Reddit). Instead of two social platforms, PHANTOM ARENA runs the same collision in 3 cultural/domain contexts simultaneously.

**Purpose**: Separate **context-invariant Visions** (universally valid) from **context-dependent Visions** (need localization) and **context-tensions** (contradictions that reveal deeper truths).

### When to activate (conditionally mandatory)

> [!IMPORTANT]
> PHANTOM ARENA is **automatically activated** when Vision output spans or impacts 2+ distinct audiences, markets, or cultural contexts. This is HA's distinctive multi-context validation feature (inspired by MiroFish). Do NOT skip when the condition is met.

- **AUTO**: Fragments span 2+ distinct domains (e.g., JP + US, B2B + B2C, tech + creative)
- **AUTO**: Vision will be applied across different markets, audiences, or domains
- **AUTO**: GHOSTY COLLIDER produced a Vision that "feels too local" or "too universal" (needs stress-testing)
- **MANUAL**: User explicitly requests `--arena` or 「複数文脈で」

### Context Selection

**First, choose your axis** (the dimension along which you want to test the Vision):

| Axis | Default 3 Contexts | When to use |
|------|-------------------|-------------|
| 🌍 **Region** | Mature Market (US/EU) / Growth Market (SEA/LATAM) / Frontier Market (Africa/India) | Cross-market products, GTM strategy |
| 🏢 **Segment** | Enterprise / SMB / Individual | B2B vs B2C, pricing decisions |
| ⏰ **Time** | Present (2026) / Near (2030) / Far (2040) | Technology bets, long-term strategy |
| 🎓 **Discipline** | Engineering / Design / Business | Feature prioritization, team alignment |
| 🎭 **Culture** | High-context (JP/KR) / Low-context (US/NL) / Hybrid (IN/BR) | UX, communication, localization |

Pick ONE axis, then use its 3 defaults (or customize). **Do not mix axes** — that makes comparison meaningless.

> The axis choice itself is a decision. If unsure, default to **Segment** (most practical) or **Time** (most strategic).

### Procedure

```
1. Run Steps 1-4 of GHOSTY COLLIDER once normally
2. Take the ⚡ Electric collisions from Step 3
3. For each ⚡ collision, re-run Step 4 (Vision Crystallization) in each Arena:

   Arena A (Context 1): What Vision emerges through this lens?
   Arena B (Context 2): What Vision emerges through this lens?
   Arena C (Context 3): What Vision emerges through this lens?

4. CONTEXT FILTER — Compare across Arenas:
   ├── 🌐 Universal:  Vision appears in ALL arenas → "Context-invariant"
   ├── 📍 Local:      Vision appears in ONE arena only → "Needs localization"
   └── ⚡ Tension:    Arenas A and B CONTRADICT → Most valuable insight
```

### Output Format

```markdown
## 🏟️ PHANTOM ARENA: [Collision Theme]

| Arena | Context | Vision | Tag |
|-------|---------|--------|-----|
| A | 🇯🇵 Japan | "Mastery through repetition" | 📍 Local |
| B | 🇺🇸 USA | "Disruption of the learning curve" | 📍 Local |
| C | 🌏 SEA | "Community-powered skill sharing" | 📍 Local |

### Context-Invariant Core
[What ALL arenas share → this is the universal truth beneath the cultural surface]

### Context Tension (Most Valuable)
[Where arenas CONTRADICT → this reveals an assumption worth examining]
```

### Anti-Pattern

| Anti-Pattern | Fix |
|---|---|
| All arenas produce the same Vision | Your contexts are too similar. Pick more divergent lenses |
| No tensions found | This is fine. Universal Visions are also valuable |
| Arena feels stereotypical | Go deeper. "Japan = harmony" is shallow. Ask "What specific constraint in this context shapes the Vision differently?" |
